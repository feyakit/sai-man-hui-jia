# 可选音效

将产品音效放到本目录，Cocos 导入后按以下固定文件名读取（MP3、44.1kHz、每个不超过 100KB）：

`pickup.mp3`、`drop.mp3`、`invalid.mp3`、`rotate.mp3`、`undo.mp3`、`tick.mp3`、`trunk_slam.mp3`、`horn.mp3`、`cheer.mp3`、`mom.mp3`。

当前不提供正式音效或静音占位。全部预加载，缺失、加载失败、尚未就绪或播放失败均静默；不会延迟补播旧动作，不阻塞游戏。

已接入：拿起、合法放下/归还、非法释放/旋转、合法旋转、撤销按钮、最后 10 秒倒计时、通关欢呼。点击选中不触发拿起声。
`trunk_slam`、`horn`、`mom` 已支持同名加载与播放接口，留给后续关盖/发车/妈妈模式调用；本任务不实现这些流程。

资源打包时需保留 `resources` bundle。浏览器音频策略可能要求用户交互后才可听到声音。
